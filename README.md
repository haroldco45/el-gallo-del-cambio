# 🐓 El Gallo del Cambio

Fábula original sobre el poder y la corrupción, contada en paralelo con los hechos reales del gobierno 2022–2026 en Colombia: caso UNGRD (carrotanques de La Guajira), sanción del CNE a la campaña de 2022, el caso de la denunciante Angie Rodríguez y el balance de Transparencia por Colombia.

## Qué trae
- 5 capítulos: fábula a la izquierda, vida real a la derecha
- Modo de lectura: Ambas / Solo fábula / Solo realidad
- Videos reales de YouTube incrustados (cargan al tocarlos, rápido en celular)
- Moraleja para hoy y sección "Para ser justos" con logros y críticas
- 19 fuentes enlazadas
- Botón para compartir por WhatsApp

## Archivos
| Archivo | Para qué |
|---|---|
| `index.html` | La app completa (fábula, videos, moraleja) |
| `manifest.json` | Nombre, colores e íconos para instalarla |
| `sw.js` | Service worker: funciona sin señal (menos los videos) |
| `icon-192.png`, `icon-512.png` | Íconos de la app |
| `og-image.png` | Imagen de 1200×630 que sale al compartir el enlace |

## Publicación
1. Crear el repo `haroldco45/el-gallo-del-cambio`
2. Subir los 7 archivos a la raíz del repo
3. Activar GitHub Pages (rama `main`, carpeta raíz)
4. Queda en: https://haroldco45.github.io/el-gallo-del-cambio/
